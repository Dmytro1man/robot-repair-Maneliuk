





                                                          Щоденник розробника
 У ході виконання першого юніту я налаштував базову сцену проекту MainScene у Unity та додав об'єкт персонажа. Для створення ігрового середовища я використав інструмент Tilemap і налаштував шар відображення Order in Layer, щоб персонаж завжди залишався поверх підлоги. Також я написав C# скрипт PlayerController, який відповідає за зчитування вводу з клавіатури та переміщення об'єкта. У коді було використано параметр Time.deltaTime для забезпечення плавності та незалежності руху від FPS. Додатково у рамках завдань з розділу More things to try я змінив швидкість переміщення персонажа та додав нові елементи підлоги з палітри плиток. Наостанок я налаштував зв'язок локального проекту з репозиторієм на GitHub та зафіксував усі зміни у комітах.
